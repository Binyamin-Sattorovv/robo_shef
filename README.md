# Кафе Робо-шеф

Учебная консольная программа для управления заказами кафе.

## Возможности

- Просмотр меню и цен
- Добавление блюд в корзину
- Проверка остатков на складе
- Оплата заказа
- Расчёт сдачи
- Печать чека
- Подсчёт выручки
- Учёт обслуженных клиентов

## Используемые технологии

- Python 3
- Функции
- Списки
- Кортежи
- Словари
- Множества
- Модули

## Запуск

```bash
python3 main.py
